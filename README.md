Font-Design-Tips  
--------

The repository includes practical tips on the work of creating fonts. It does not aim to create a systematic description of the font creation process, but rather to draw attention to various aspects of font construction that inevitably arise as problems, especially when creating multilingual fonts with extended Unicode support.
